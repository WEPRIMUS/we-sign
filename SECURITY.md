# Security

Report a security problem in WE Sign by e-mail to **support@we-primus.com**, not in a public issue. Say what you
found, how to reproduce it, and which version (commit) you tested. We confirm receipt, work out the fix with you, and
publish it once it is fixed.

WE Sign is based on DocuSeal. A problem that is also in upstream DocuSeal is reported to its maintainers as well.
